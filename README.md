# Thread em Python – Processamento Concorrente

## 📌 Descrição do Projeto

Este projeto demonstra o uso de **threads em Python** para execução concorrente de tarefas, aplicando conceitos fundamentais de **programação concorrente**. O objetivo é ilustrar como múltiplas threads podem ser criadas e executadas de forma paralela, melhorando a organização e a eficiência do processamento.

O código foi desenvolvido com fins **didáticos**, sendo ideal para o entendimento de como funcionam threads, criação de processos concorrentes e sincronização básica em Python.

---

## 🧠 Conceitos Abordados

* Programação concorrente
* Criação e execução de threads
* Execução paralela de tarefas
* Organização de fluxo de execução
* Introdução ao uso do módulo `threading`

---

## 🧰 Tecnologias Utilizadas

* Python 3
* Módulo `threading`

---

## ▶️ Como Executar o Projeto

### 1️⃣ Pré-requisitos

* Python 3 instalado

### 2️⃣ Executar o programa

No diretório do projeto, execute:

```bash
python thread.py
```

O programa iniciará múltiplas threads e exibirá no terminal a execução concorrente das tarefas.
